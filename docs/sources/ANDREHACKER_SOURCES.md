# External sources integrated from andrehacker GitHub

The following material from https://github.com/andrehacker was examined and selectively integrated:

## Directly included

- **encyclopaedia-britannica.txt**  
  Source: https://github.com/andrehacker/mapred/blob/master/testdata/books/encyclopaedia-britannica.txt  
  Content: Project Gutenberg EBook of Encyclopaedia Britannica, 11th Edition, Volume 4, Part 3 (“Brescia” to “Bulgaria”).  
  Status: Public domain (pre-1931 publication + Gutenberg release).  
  Location in this project: `data/sample_corpus/encyclopedia/encyclopaedia-britannica-11th-vol4-part3.txt`

## Examined but not bulk-copied

- **mapred** – MapReduce / Stratosphere job examples and test data. Useful as historical context for distributed classical computation; only the public-domain Britannica volume was retained.
- **logreg** – Parallel logistic regression implementations (Java / Hadoop / Stratosphere). Classical statistical learning reference; code not required for the current Python classical core.
- **virtual-schemas** – Exasol virtual schemas framework (fork). Database connectivity patterns; not required for the local SQLite Archive.
- **Public-Knowledgebase** – Exasol product knowledge-base Markdown templates and articles. Structure (Q&A / Explanation / Tutorial templates) is a useful reference for future Archive document styles, but the content is product-specific.

All retained text is either original to BODY OF SECRETS or confirmed public-domain.
